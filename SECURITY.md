# Security Policy

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not disclose exploitable details in a public issue or discussion.

Include the affected component, reproduction conditions, expected impact, and any suggested mitigation. Remove credentials, personal information, internal tool content, and production data from all reports.

## Supported Version

The latest release on the default branch receives security fixes. Pre-release versions may change without backward-compatibility guarantees.

## Deployment Responsibility

This project provides application-level safeguards and deployment templates, but every operator remains responsible for identity integration, network controls, TLS, secret management, malware scanning, backups, monitoring, capacity testing, and security acceptance in their own environment.
