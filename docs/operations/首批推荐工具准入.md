# 首批推荐工具准入

“首批推荐”是平台运营位，不是普通标签，也不由下载量自动决定。正式环境默认没有推荐工具，维护人员从真实已上架资产中逐个确认。

## 准入条件

工具进入首批推荐前必须同时满足：

1. 当前默认版本已上架，文件可通过受控下载取得；
2. 自动预检无“必须修复”项；
3. 工具名称、解决问题、使用效果、实现原理、业务模块和功能分类完整；
4. 包内包含统一 README、生产标准、Agent 修改边界与版本规则；
5. 已记录 SHA-256、文件大小、标准版本和版本说明；
6. 验证状态至少为“部分验证”，并明确写出未验证范围和风险；
7. 能代表一个清晰、常见场景，不与已推荐工具仅做同义重复。

## 维护方式

- 在维护系统的工具资产详情进入“工具资料”，点击“加入首批推荐”；
- 只有已上架工具可加入；
- 用户侧“首批推荐工具”独立筛选，不改变正常的最新发布和下载采用排序；
- 工具下架后自然不会出现在用户目录；重新上架不自动恢复推荐资格；
- 第一批建议控制在 3–10 个，覆盖不同模块后再逐步扩充。

推荐顺序当前默认写入 `100`。数据模型已保留精细排序字段，后续增加推荐位管理页时可直接调整，无需改变工具与版本结构。
